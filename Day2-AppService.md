# Day 2 - Azure App Service

## What is Azure App Service?

Azure App Service is a Platform as a Service (PaaS) offering that hosts:

- ASP.NET Core
- Node.js
- Java
- Python applications

## Benefits

- No server management
- Automatic scaling
- SSL support
- Deployment slots
- CI/CD integration

## Hands-on Completed

- Created ASP.NET Core Web API
- Created Azure App Service
- Published API to Azure
- Verified application URL

## Key Learning

Local App → Publish → Azure App Service → Public URL
