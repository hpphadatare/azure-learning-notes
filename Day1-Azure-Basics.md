# Azure Day 1

## Azure Hierarchy

Subscription
  -> Resource Group
      -> Resources

## Key Concepts

### Subscription
Billing and management boundary.

### Resource Group
Logical container for Azure resources.

### Region
Physical Azure datacenter location.

### Resource
Any Azure service.

Examples:
- App Service
- Azure SQL
- Storage Account
- Key Vault
